# Week 04: UI Fundamentals & Design Principles

## 01. Week Overview

This week introduces the fundamentals of User Interface (UI) design and the visual principles behind creating clear, organized, and visually appealing digital interfaces.

You will learn how designers use colors, typography, spacing, alignment, contrast, and visual hierarchy to communicate information effectively and create consistent interfaces.

The goal is to understand the foundations of good visual design before moving on to designing interfaces using Figma.

## Learning Goals

By the end of this week, you should be able to:

- Understand the fundamentals of UI design.
- Identify the main elements of visual design.
- Apply visual hierarchy to organize information.
- Work with contrast, alignment, proximity, and balance.
- Apply basic Gestalt principles.
- Choose appropriate typography for digital interfaces.
- Understand color theory and build a simple color palette.
- Use spacing and consistency to create organized layouts.
- Recognize common visual design mistakes.

### Task

1. Watch all the assigned videos and read the recommended articles in the given order.
2. Write a short summary of each resource in your own words, highlighting the most important concepts you learned.
3. Create a simple **UI Principles Cheat Sheet** that includes the main principles you studied, with a short explanation and a visual example for each one.
4. Choose 2 different screens from existing websites or mobile applications.
5. Analyze the selected screens and identify at least **5 examples** of UI design principles being applied successfully or incorrectly.
6. Explain your observations, mentioning the relevant design principle in each example.

### Don't just memorize design principles. Learn to recognize them, understand their purpose, and know when to apply them.
