# Week 05: UX Principles & Laws

This week explores the psychological principles and UX laws that influence how users interact with digital products.

You will learn how users make decisions, interact with interface elements, process information, and develop expectations when using websites and applications.

You will also discover how designers use these principles to reduce friction, simplify interactions, and create more intuitive user experiences.

The goal is to understand the reasons behind good UX decisions, not just memorize design rules.

## Learning Goals

By the end of this week, you should be able to:

- Understand what UX Laws are and why they matter.
- Understand how human behavior and psychology influence UX design.
- Learn the most important UX Laws and their applications.
- Understand how users make decisions and process information.
- Recognize common UX problems in digital interfaces.
- Evaluate design decisions from a user-centered perspective.
- Apply UX Laws to improve usability and user interactions.

### Task

1. Read all the recommended resources in order.
2. Write a short summary of each resource in your own words.
3. Create a simple **UX Laws Cheat Sheet** explaining the main laws with a practical example for each.
4. Choose 2 existing websites or mobile application screens.
5. Analyze the selected screens and identify at least **5 UX issues**.
6. Connect each identified issue to the relevant UX Law or usability heuristic.
7. Suggest improvements for the identified issues and explain how they would make the experience easier for users.
