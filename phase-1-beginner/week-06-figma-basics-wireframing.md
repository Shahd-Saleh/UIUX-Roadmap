# Week 06: Figma Basics & Wireframing

This week introduces Figma, one of the most widely used tools in UI/UX design.

You will learn how to navigate the Figma interface, use its essential tools, organize your design files, and create basic interface layouts.

You will also explore Wireframing and learn how to translate ideas and user needs into simple, low-fidelity layouts before moving into detailed visual design.

The goal is to become comfortable using Figma and understand how to structure digital interfaces.

## Learning Goals

By the end of this week, you should be able to:

- Navigate the Figma interface and workspace.
- Create and organize design files.
- Work with Frames, Layers, Groups, and Pages.
- Use basic tools such as Shapes, Text, and Images.
- Apply alignment, spacing, and layout grids.
- Explain the purpose of Wireframing.
- Distinguish between Low-Fidelity and High-Fidelity Wireframes.
- Create simple wireframes for mobile apps or websites.
- Organize interface elements according to content hierarchy.
