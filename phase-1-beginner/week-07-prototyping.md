# Week 07: Prototyping

This week focuses on Prototyping and bringing static designs to life.

You will learn how to connect screens, create interactions, and simulate user journeys using Figma's prototyping tools.

You will explore different interaction triggers, transitions, overlays, and basic animations to create interactive experiences that demonstrate how a digital product works.

The goal is to transform static UI screens into interactive prototypes that communicate the intended user experience.

## Learning Goals

By the end of this week, you should be able to:

- Explain what Prototyping is and why it matters in UI/UX design.
- Distinguish between Low-Fidelity and High-Fidelity Prototypes.
- Understand how Wireframes, UI Designs, and Prototypes relate to one another.
- Navigate Figma's Prototype tab.
- Connect frames and create interactive flows.
- Work with interaction triggers and actions.
- Apply basic transitions and animations.
- Create overlays and interactive menus.
- Understand Smart Animate and its basic applications.
- Preview and share interactive prototypes.

### Task

1. Open the wireframes you created in Week 06.
2. Add interactions to buttons and clickable elements.
3. Use different triggers and transitions to make the experience feel realistic.
4. Create at least one interactive element, such as a popup, dropdown, or overlay.
5. Apply Smart Animate at least once.
6. Preview your prototype and make sure all interactions work as expected.
