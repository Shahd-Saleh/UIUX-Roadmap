# Week 10: Research Synthesis & User Insights (Understand)

This week focuses on transforming raw research data into meaningful user insights.

You will learn how to analyze research findings, identify patterns, understand user behaviors, and uncover the real needs, motivations, and frustrations behind users' actions.

The goal is to move beyond collecting information and develop a deeper, evidence-based understanding of your users.

## Learning Goals

By the end of this week, you should be able to:

- Analyze and interpret user research data.
- Identify recurring patterns and behavioral trends.
- Extract meaningful insights from research findings.
- Understand user needs, motivations, and frustrations.
- Create evidence-based user personas.
- Visualize the user experience through journey mapping.
- Define clear problem statements and design opportunities.

### Task

1. Review and organize your research findings using an **Affinity Map**.
2. Identify recurring patterns, user needs, and pain points.
3. Extract at least **3 evidence-based User Insights**.
4. Create **1–2 User Personas** based on your research.
5. Create an **Empathy Map** for your primary persona.
6. Create a **User Journey Map** for one key user scenario.
7. Highlight the main opportunities for improving the user experience.
